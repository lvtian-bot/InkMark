# 桌面与设置

## 职责与边界

负责应用生命周期、窗口、文件关联、原生菜单、主题、设置、语言、快捷键、安装与更新。菜单触发文档操作时复用渲染层文件流程，不在菜单层另建正文状态。

## 当前实现与数据归属

- `src/main/index.ts` 管理单实例和窗口，接收启动及第二实例的文件参数，通过 preload 转交打开事件；持久化窗口状态、启动主题、最近记录及对话框位置。
- `src/renderer/src/settings.ts` 校验、迁移与持久化设置，store 应用当前值；语言与快捷键定义位于 `src/shared/i18n/` 和 `shortcuts.ts`。
- 原生菜单的勾选、快捷键、语言及标题栏颜色由渲染层经 IPC 同步；主题首帧用主进程保存的上次值，加载设置后再同步最终值。
- 样式位于 `src/renderer/src/styles/`，分外壳主题与内容主题；细节以 [主题架构](../theme-architecture.md) 为准。

## 更新与安装

`src/main/update-service.ts` 封装检查、下载、进度与安装状态，`resolve-auto-updater.ts` 处理运行时导入；预加载提供查询和事件订阅，`UpdateDialog.tsx` 展示状态。自动下载及退出时自动安装关闭，由使用者分别触发操作。

`update-install.ts` 在安装前执行关闭准备，未保存内容处理取消时不得继续安装。Windows 打包、文件关联与发布源由 `package.json` 定义，安装迁移脚本为 `build/installer.nsh`。

既有设计说明：[手动更新](../superpowers/specs/2026-08-13-manual-update-design.md)、[Windows 安装迁移](../superpowers/specs/2026-08-13-windows-installer-migration-design.md)。这些文档提供设计背景，操作前仍须核对当前代码和配置；正式发版遵循 AGENTS.md 指向的用户级 electron-app-release 技能。

## 必须保持的约束

- 保持进程隔离、IPC 校验和窗口导航限制，不能为原生能力扩大渲染层权限。
- 新增设置须校验持久化值，保留旧设置迁移路径；不持久化标签正文到设置。
- 主题改动须同步原生标题栏与启动底色，不能只改 CSS。
- 不手改 `out/`、`dist/` 或第三方依赖生成产物。
- 更新服务检查通过不等于实际安装与迁移验收；运行时改动需针对性验证。

维护策略见 [依赖管理](../dependency-management.md)。自动验证入口包括 `update-service.test.ts`、`resolve-auto-updater.test.ts`、`update-install.test.ts` 及快捷键、语言与排版相关测试。整体关系见 [技术架构](../技术架构.md)。
