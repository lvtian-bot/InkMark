# 外部审阅

## 职责与边界

把一轮外部修改展示为可逐块接受或拒绝的源码差异，并在保存时保护原件。只在源码模式提供，不调用 AI、不组织多轮合并、不保存长期改动历史。

## 当前流程与状态

`src/renderer/src/hooks/useFile.ts` 处理入口和保存编排；`review/review-store.ts` 按标签保存磁盘基线及待注入块，补齐未上报编辑后计算差异并固定本轮版本。`review-diff.ts` 按行生成、合并和锚定块，`review-extension.ts` 在 CodeMirror 中显示并执行决定。

当前正文是已决定结果：未决删除侧标记在正文上，未决新增侧仅为装饰层 widget。标签的 `pendingReviewCount` 与 `reviewSession` 分别表示待决数量和尚未提交的会话，数量归零不代表已经保存。

有未决块时只读；处理完后可调整结果，但保存成功前仍锁定模式切换并暂停自动保存。后续外部修改只标记冲突，不重写本轮决定。最后一块及批量决定经过确认，取消后保留内存结果并提供重试入口。

## 写回接口与约束

`src/main/review-file-save.ts` 在写回前稳定读取原文件，比较本轮原始正文与修改时间。匹配才保存原件；版本不同、文件消失或核验失败时仅允许另存新副本。副本以排他创建写入，不覆盖原件或已有文件，附件复制由图片模块处理。

- 决定不进入普通撤销历史，避免正文与块状态回滚错位。
- 锚定失败不能把未显示块视为已经处理；后台标签须保留待注入队列。
- 新增侧 widget 当前不参与选择复制；大段移动按删除加新增显示。
- 不提供文件锁或崩溃恢复；核验至替换间仍存在短并发窗口。
