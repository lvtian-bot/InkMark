# 标签页编辑位置记忆设计

日期：2026-08-10

状态：方案已确认，待实现

## 目标

切换标签页或编辑模式后，InkMark 应恢复当前文档在对应编辑模式中的浏览位置和光标位置，使用户回到原来正在阅读或编辑的地方。

本次只处理当前应用会话内的状态，不把浏览位置或光标位置写入 Markdown 文件，也不写入全局设置。

## 当前问题

标签页目前只有一个 `scrollTop`，切换标签页时始终通过 WYSIWYG 编辑器接口读取和恢复它。源码模式实际由 CodeMirror 的 `.cm-scroller` 负责滚动，但 `SourceEditorHandle` 没有滚动接口，因此源码模式的滚动位置不会被正确保存。

光标和撤销历史已经通过 `editorStateCache` 按标签页、按编辑模式保存。只要文档内容与快照一致，恢复编辑器状态即可恢复光标；本次不重复建设一套独立的光标坐标存储。

## 方案

### 1. 按标签页、按模式保存滚动位置

将标签页的位置状态拆成两个字段：

- `wysiwygScrollTop`：所见即所得模式对应 `.editor-container` 的滚动位置。
- `sourceScrollTop`：源码模式对应 CodeMirror `.cm-scroller` 的滚动位置。

两个字段均以 `0` 为初始值，仅存在于当前会话的标签页状态中。旧的单一 `scrollTop` 字段不再作为跨模式位置使用，避免把一种模式的坐标误用于另一种模式。

### 2. 扩展源码编辑器窄接口

在 `SourceEditorHandle` 中增加：

- `getScrollTop()`：读取 CodeMirror `.cm-scroller.scrollTop`。
- `setScrollTop(top)`：在编辑器可见后恢复滚动位置。

`SourceEditor` 只通过自身的 `view.scrollDOM` 暴露这两个操作，调用方不直接依赖 CodeMirror 的 DOM 查询。恢复值由浏览器按实际文档高度自然限制在合法范围内。

### 3. 统一标签页和模式切换流程

切换标签页时：

1. 从旧标签页当前模式的编辑器读取滚动位置。
2. 按当前模式保存旧标签页的编辑器状态和 Markdown 内容。
3. 恢复新标签页当前模式的编辑器状态或内容。
4. 在编辑器完成状态切换且下一帧可见后，恢复新标签页对应模式的滚动位置。

切换编辑模式时：

1. 保存离开模式的编辑器状态、Markdown 内容和该模式滚动位置。
2. 恢复目标模式的编辑器状态或内容。
3. 在目标模式可见后恢复该标签页对应模式的滚动位置。

编辑器状态缓存继续负责光标、选区和撤销历史。若 Markdown 内容已变化，缓存按现有规则失效，编辑器从新内容初始化，光标回到该编辑器的默认合法位置；滚动位置仍恢复并由浏览器自动约束。

### 4. 保持现有状态边界

- 不把位置状态提升为独立的顶层镜像状态，仍归属于 `tabs[]` 中的标签页。
- 不持久化到 localStorage、用户配置或 Markdown 文件。
- 不修改文件保存、外部变更冲突和文档序列化逻辑。
- 不为普通滚动增加高频 Zustand 更新；只在切换标签页或模式时捕获位置。

## 测试与验收

### 自动化测试

- 标签页初始具有两个独立的滚动位置，均为 `0`。
- 更新 WYSIWYG 位置不会改变源码位置，反之亦然。
- 切换或关闭标签页不会把一个标签页的位置写入另一个标签页。
- 现有编辑器状态隔离测试继续通过，确保光标和撤销历史仍按标签页、按模式隔离。

### 人工验收

准备两篇足够长的 Markdown 文档：

1. 在 WYSIWYG 文档 A 滚动到中下部并把光标放在正文中，切换到文档 B，再切回 A，确认滚动位置和光标均回到原处。
2. 在源码模式对文档 A 重复上述操作，确认 CodeMirror 滚动位置和光标恢复。
3. 在同一个标签页分别记录 WYSIWYG 与源码模式的不同位置，来回切换模式，确认两种位置互不覆盖。
4. 编辑内容后再切换标签页，确认不会抛出错误，也不会把滚动位置恢复到另一个标签页。

## 失败处理

编辑器句柄尚未建立、文档处于开始页或切换期间句柄暂时不可用时，位置捕获和恢复应安全跳过，不阻断标签页切换。已有的 `editorStateCache` 内容匹配规则继续作为光标快照的安全边界。
