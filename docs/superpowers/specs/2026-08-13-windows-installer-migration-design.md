# Windows 安装范围与迁移设计

## 目标

InkMark 的 Windows 安装包采用可见的向导式安装，允许用户选择“仅为当前用户安装”或“为所有用户安装”，但不开放任意安装目录。升级或切换安装范围时，安装器自动处理旧程序，不要求用户先去系统设置中卸载，也不允许最终留下两套 InkMark。

## 用户可见行为

- 首次安装时展示安装范围选择，默认“仅为当前用户安装”。
- 当前用户安装使用 Windows 用户级标准程序目录；所有用户安装使用 `Program Files` 标准目录。
- 不展示自定义路径页面。
- 选择所有用户安装，或需要清理已有的所有用户安装时，才请求管理员权限。
- 用户取消管理员授权后，安装流程终止，原安装保持可用，不写入第二套程序。
- 安装完成后创建桌面和开始菜单快捷方式，并提供“运行 InkMark”选项。

## 升级与迁移规则

### 同一安装范围升级

安装器沿用已登记的安装范围和安装目录。它调用旧版卸载清理程序文件、快捷方式和安装登记，同时使用保留应用数据参数，然后将新版写入原目录。这里不采用文件直接覆盖，因为新版可能删除或改名资源，直接覆盖会留下旧文件。

### 当前用户版迁移为所有用户版

安装器请求管理员权限，自动清理当前用户版并保留应用数据，然后将新版安装到所有用户标准目录。electron-builder 25 的默认 NSIS 模板已经支持这条路径。

### 所有用户版迁移为当前用户版

这是 electron-builder 25 默认模板未完整处理的路径。InkMark 增加自定义 NSIS 迁移逻辑：用户确认选择当前用户安装后，如果检测到已有所有用户安装，则通过 UAC 启动具备管理员权限的清理过程；清理成功后继续当前用户安装。

如果提权被取消、旧版卸载程序不可用或清理返回失败，安装器停止安装并给出明确错误，不创建当前用户版。不得通过忽略失败继续安装来形成双版本。

## 技术边界

- 保留 electron-builder 自带的同范围升级和“当前用户到所有用户”迁移逻辑，不复制或替换整套 NSIS 模板。
- 通过 `build/installer.nsh` 扩展 electron-builder 支持的自定义 include 接缝，仅补“所有用户到当前用户”迁移。
- 自定义逻辑以注册表中的 InkMark 安装登记为依据，不扫描磁盘猜测安装目录。
- 清理旧版必须调用已登记的旧版卸载程序，并传递保留应用数据参数；不直接递归删除目录。
- 用户设置、最近文件等应用数据不随升级或安装范围迁移删除；用户自己的 Markdown 文件始终不在安装器管理范围内。
- 不支持同一台电脑同时保留当前用户版和所有用户版；检测到双份历史安装时，安装器必须收敛为用户本次选择的唯一安装范围。

## 失败处理

- InkMark 正在运行时，沿用 electron-builder 的关闭提示和重试机制。
- UAC 被取消：停止迁移并保持旧版本。
- 旧版卸载失败：显示安装失败并停止，不写入新版。
- 注册表存在但卸载程序缺失：显示旧安装损坏，停止安装；不删除未知目录。
- 清理完成但新版写入失败：报告安装失败。此时旧程序可能已被移除，但应用数据仍保留，用户可重新运行安装包恢复。

## 验收

至少使用两个连续测试版本验证以下路径：

1. 无旧版本 → 当前用户安装。
2. 无旧版本 → 所有用户安装。
3. 当前用户版 → 当前用户版升级。
4. 所有用户版 → 所有用户版升级。
5. 当前用户版 → 所有用户版迁移。
6. 所有用户版 → 当前用户版迁移。
7. 在第 6 条迁移时取消 UAC，确认原系统版仍可使用且没有个人版。
8. 人为制造两套历史安装后重新安装，确认最终只保留用户所选范围。

每条路径均检查：已安装应用中只有一个 InkMark、旧程序目录已清理、新程序可启动、桌面与开始菜单快捷方式指向新路径、`.md` 和 `.markdown` 文件关联有效、应用设置仍保留。

## 不在本次范围

- 任意盘符或自定义目录。
- 自动更新下载与重启安装。
- Windows 代码签名。
- 删除应用数据或用户文档。
