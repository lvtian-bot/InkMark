## 记录规则

1. 所有任务分为三类：**新功能**、**Bug 修复**、**暂不考虑**。
2. 新增任务一律追加到对应分类末尾。
3. 任务完成后标记 `[x]` 并按 Obsidian Tasks 格式记录完成时间：`✅ YYYY-MM-DD`。已完成项说明保持简短（最多三条）。
4. 版本发布时，将已完成的 `[x]` 项统一剪切归档至 [TODO-ARCHIVE.md](./TODO-ARCHIVE.md) 对应版本下，保持待办清单精炼聚焦。

## Bug 修复

- [ ] 保存能力的信任模型专项（待评估）
  - 可打开扩展名放宽后，写文件原语覆盖代码与脚本；现行「本会话已打开即可保存」校验的登记入口由渲染层发起，被攻破的渲染层可自我授权。需要设计哪些打开流程构成可信能力（原生对话框、系统打开等），统一覆盖 file:save 与审阅保存。

- [x] 按正文引用收集另存附件 ✅ 2026-11-06
  - 普通另存与审阅副本跨目录时按实际引用复制本地图片、更新路径并同步标签正文；同目录保留原引用，缺图或复制失败时明确提示。规则见 [图片与链接](./图片与链接/图片与链接.md#另存图片)。

- [x] 新建文档自动补全 Markdown 扩展名 ✅ 2026-11-06
  - 新建文档输入不含扩展名的名称时自动创建 `.md` 文件；显式扩展名保留并按白名单校验，重命名规则不变。
