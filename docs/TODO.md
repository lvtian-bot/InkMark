## 记录规则

1. 所有任务分为三类：**新功能**、**Bug 修复**、**暂不考虑**。
2. 新增任务一律追加到对应分类末尾。
3. 任务完成后标记 `[x]` 并按 Obsidian Tasks 格式记录完成时间：`✅ YYYY-MM-DD`。已完成项说明保持简短（最多三条）。
4. 版本发布时，将已完成的 `[x]` 项统一剪切归档至 [TODO-ARCHIVE.md](./TODO-ARCHIVE.md) 对应版本下，保持待办清单精炼聚焦。

- [x] 添加快捷键，实现快速输入当前日期和时间 ✅ 2026-09-23
  - Ctrl/Cmd+; 插入当前日期，Ctrl/Cmd+Shift+; 插入日期和时间；所见即所得与源码模式均生效，可在设置中改键。

- [x] 开始页新增「上中下」版式，可在设置中切换 ✅ 2026-09-29
  - 设置 → 外观新增「开始页版式」：双栏保持原有布局，上中下为「新建」（横排按钮）、「星标」、「最近打开」三段纵向排列，星标与最近列表两列展示；星标项单独成区，「最近打开」只列未加星条目。
  - 上中下版式下「清除全部」只清空「最近打开」区的未加星条目，星标需逐条取消；双栏版式行为不变。

- [x] 文件树基础操作 ✅ 2026-10-13

## Bug 修复

- [ ] 保存能力的信任模型专项（待评估）
  - 可打开扩展名放宽后，写文件原语覆盖代码与脚本；现行「本会话已打开即可保存」校验的登记入口由渲染层发起，被攻破的渲染层可自我授权。需要设计哪些打开流程构成可信能力（原生对话框、系统打开等），统一覆盖 file:save 与审阅保存。

- [ ] 按正文引用收集另存附件（待评估）
  - 另存为按文档当前名定位 `<名>.assets` 目录，文档改名后（无论经本应用或资源管理器）另存副本会丢失附件；改为按正文实际引用的相对路径收集附件可覆盖全部改名场景。

- [x] 修复外部改动审阅中纯新增块的接受/拒绝按钮被挤到未改动段落行首 ✅ 2026-09-25
  - 行级 diff 的插入文本含行尾换行，pre-wrap 下按钮被断行推到下一行，看似挂在未改动段落上；尾部换行拆到按钮之后，按钮停在绿色文本行尾。
