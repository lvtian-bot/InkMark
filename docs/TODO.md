## 新功能

- [x] 点击文件链接跳转 ✅ 2026-09-12
  - 两种模式统一手势：Ctrl/Cmd+点击跳转（文档链接开应用内标签、外链交系统浏览器），普通点击保留光标放进链接编辑；所见即所得下按住 Ctrl/Cmd 悬停链接时显示手指提示

  - 修复：ProseMirror 内置「修饰键单击=选中整个块节点」与跳转手势同键位冲突，跳转瞬间段落被标记节点选中留下蓝色描边并随标签缓存；已在编辑器内注册 handleClick 拦截，块的拖拽仍由块把手承担

  - 相对路径由主进程 `path.resolve` 以所在文档目录为基准解析，之后走既有打开流程：同文件去重激活标签、目标丢失弹窗提示

  - 边界：纯页内锚点、非文档类本地文件、`file://` 等协议维持现状不处理；带锚点的文档链接只跳文件不定位标题

- [x] 导出 HTML / PDF ✅ 2026-09-12
  - 文件菜单「导出」子菜单；渲染链路与编辑器同源（commonmark + GFM + frontmatter），换行遵循宽松/严格换行设置，原始 HTML 按字面文本转义

  - HTML 为单文件自包含：本地图片内嵌 base64，http/data 引用原样保留；PDF 由隐藏窗口 printToPDF 生成（A4、打印背景、标题书签大纲），本地图片走 file://

  - 已知边界：代码块无语法高亮；页内锚点链接不生成跳转目标

## Bug 修复

- [x] 待办框和文字不对齐的bug重新出来 ✅ 2026-09-10
  - 根因：复选框固定 16px 且 `text-bottom` 把框底钉在字体内容区底部，比中文墨迹底低 2-4px；字号 18/20px 时框中心最多偏低 6px（默认字号仅偏 2px，不易察觉）

  - 修复：框改为 0.9em 随字号缩放 + `vertical-align: -0.1em`，7 种字体 × 4 档字号实测中心偏差 ≤1.3px；`margin-right: calc(24px - 0.9em)` 保持框+间距恒为 24px，首行/换行/普通列表文字水平零错位

  - 验证方式：离屏 Chromium 布局测量（`getBoundingClientRect` + canvas 墨迹），无逻辑改动故未加单元测试

- [x] 审阅模式：改动块后方的折叠把绿色新增一起吞掉，默认不可见 ✅ 2026-09-05
  - 折叠起点与块尾新增 widget 重合时该行保持可见，从下一行起折叠

  - 替换块与纯新增块两条路径补了真实渲染回归测试

- [x] 应用图标替换为绿色 M 新设计 ✅ 2026-09-12
  - `build/icon.png` 换为 1024px 新图；沿用旧图标的圆角 alpha 蒙版，四角透明，弧度与原风格一致

  - 原图右下角的 AI 水印星标恰好落在圆角裁切区内，无需修补；`.md` 文件关联图标不受影响
