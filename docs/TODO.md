# InkMark 待办

产品出发点、定位与边界见 [product-positioning.md](./product-positioning.md)。

待办记录的任务不代表一定要做，是可以探讨的。如果在实现过程当中会带来更大的问题，或者是说成本大于收益，必须要提出来。

## 记录规则

1. 所有任务必须归入以下五个分类之一：体验与界面、编辑与文件、稳定性与安全、工程与发布、暂不需要。
2. 本次分类迁移完成后，以现有顺序为基准；新增任务一律追加到对应分类的末尾，不插入已有任务之间，不因开始或完成而移动位置。
3. 任务完成后只把 `[ ]` 改为 `[x]`，并在任务末尾按 Obsidian Tasks 格式记录完成时间：`✅ YYYY-MM-DD`。
4. 未完成任务不写完成时间；无法从历史记录确认日期的完成项标记 `✅ 日期待核`。
5. 同一任务只能出现一次。需要调整分类、顺序或新增分类时，先确认再修改。
