# 外部改动审阅简化方案

2026-09-13 确定。本文替代原来的分轮审阅、可恢复草稿和三方对比讨论稿；具体行为同步记录在 [外部改动审阅](./change-review.md)。

## 审阅期间

进入审阅时固定本轮外部版本。顶部始终显示提醒：

> 审阅期间请勿使用其他软件或 AI 修改此文档，以免内容冲突或丢失。

这只是提醒，程序不锁住原文件。外部仍可继续写入；检测到更新时，页面标明本轮结果只能另存，不把新变化加入当前审阅，也不改变已经做出的接受、拒绝决定。

## 处理完成与保存

1. 逐项处理最后一处改动后，弹窗确认是否保存。全部接受、全部拒绝及退出时的批量决定先确认，再走同一个保存入口。
2. 保存原文件前，读取并比较本轮固定版本的原始正文和修改时间；确认框期间发生的修改也由主进程在写入前再次检查。
3. 版本一致才写回原文件。版本不一致、文件消失或无法核验时，不提供强制覆盖；提示另存新版本，自行比较处理。
4. 另存必须创建新文件。选择原路径或已有文件时，提示换一个文件名。另存成功后，当前标签切换到新文件并结束审阅，原文件保留外部版本。

普通保存、另存为、关闭标签和退出窗口遵守同一规则。审阅会话结束前自动保存暂停，不能因为待审数量变成零而绕过检查。

## 取消以后，结果放在哪里

取消确认或取消另存后，已经审完的结果保留在当前标签的内存中，显示未保存，工具条提供「保存审阅结果」重试入口。不会用磁盘新版本替换它，也不要求重做本轮决定。

仍有待审内容时保持只读；全部处理后可以调整结果。关闭未保存标签时仍需明确选择保存、丢弃或取消；保存失败或取消不能按保存成功关闭。未完成的审阅关闭前另行确认丢弃。

本方案不自动保存临时文件或恢复草稿。明确丢弃、程序崩溃或断电会丢失尚未保存的结果；需要保留时应完成另存。

## 能力边界

另存后两份文件的比较、合并由使用者处理，InkMark 不继续组织下一轮，也不自动解决同一位置的冲突。

保存前核验能拦截已经发生的外部更新，但不等于文件锁。核验与替换原文件之间仍有很短的并发窗口，因此不承诺在外部持续写入时绝对不会冲突。副本通过排他创建避免覆盖已有文件。
