# 图片与链接

## 职责与边界

负责本地图片插入、存储、显示、另存附件复制，以及文档链接的安全解析与跳转。不引入私有文档格式，不提供知识库链接体系。

## 图片流程与状态

`src/renderer/src/image-upload.ts` 接收粘贴或拖入的图片，通过 preload 交给 `src/main/image-storage.ts` 保存，随后将相对路径写入图片节点。图片显示由 `plugins/image-view.ts` 调用主进程解析图片来源。

新文档须先保存才能插入本地图片。上传前捕获标签和文件路径，结束时核对身份；已切换文档时不把图片插入其他标签，并清理本次已存附件。上传状态提供给关闭、另存等操作等待或拦截。

主进程检查图片类型、大小和附件路径；普通另存与审阅副本调用附件复制能力，保持关联图片可用。支持 PNG、JPEG、GIF、WebP、SVG，当前单张上限 50 MB。具体命名及复制规则以 `image-storage.ts` 为准。

### 另存图片

- 同目录另存或仅改文档名时保留原图片目录与正文引用，不强制改名附件目录。
- 跨目录另存由 `markdown-image-references.ts` 通过 remark 判断内联图片和实际使用的引用式图片定义，并用相同语法扩展下的 micromark 标记取得原文地址区间，避免手写括号扫描误判图片说明中的链接、HTML 或代码。按真实路径收集本地图片，不依赖源文档当前名称，也不复制未引用文件。原始 HTML 在编辑器中按文本显示，不作为图片引用收集。
- 图片复制到目标文档的 `<目标名>.assets`，副本正文只局部改写图片地址，保留其余文字、标题、空白和换行。支持相对路径、绝对路径和 `file:` 地址；在线图片引用保持原样。不同来源的同名图片分配新名称，不覆盖目标已有图片；源图片保留。
- 缺失、不可读取、不支持或超限的本地图片会中止另存并返回明确错误，不写出缺图副本；附件复制自身失败时清理本次新建图片，保留已有文件。
- 主进程返回实际落盘正文；渲染层同步标签 `sourceContent`、磁盘基线及可见编辑器，并作废该标签旧编辑器缓存。等待另存期间正文或文档身份已变时，不用旧快照改写覆盖新内容或其他标签。

## 链接流程与接口

`src/shared/document-link.ts` 分类链接，`src/main/document-link-resolver.ts` 解析本地目标；渲染层 `document-link.ts` 与 `source-link.ts` 提供两个模式的跟随入口。Ctrl 点击（macOS 为 Cmd）跟随链接，普通点击用于编辑。

文档链接解析后复用已有打开流程；外链通过主进程交给系统。未保存文档没有相对路径基准，不猜测目标目录。

## 必须保持的约束

- Markdown 内保存相对图片引用，不把显示用 URL 写回正文。
- 异步图片解析及上传须防止迟到结果覆盖新文档或新图片来源。
- 主进程负责本地资源访问和允许的链接范围；渲染层不能绕过预加载。
- 缺失或不可读取图片要保留正文引用与错误信息，不能静默删除内容。
- 另存必须按正文实际引用寻找本地图片；文档改名后，仍可能引用旧名附件目录或其他目录。
- 图片文件名的长度限制按完整 Unicode 字符截断，不能拆开 emoji 等补充字符后再进行 URL 编码。

接口类型见 `src/shared/image-storage.ts`、`save-as.ts` 与 `document-link.ts`；附件另存验证入口为 `image-storage.test.ts`、`markdown-image-references.test.ts` 与 `hooks/useFile-save-as.test.tsx`，链接验证入口为主进程及渲染层的 `document-link*.test.ts`、`source-link.test.ts`。图片重开、另存与插入场景见 [兼容性回归](../markdown-compatibility.md)。整体关系见 [技术架构](../技术架构.md)。
