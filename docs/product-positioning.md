# InkMark 产品定位

本文记录 InkMark 已经明确的产品出发点、定位、边界和长期方向。

## 场景由来

AI 正在参与越来越多的办公文档处理，并直接生成、整理和修改 Markdown 文件。Markdown 适合 AI 读写，也方便作为本地文件保存，但日常办公人员仍然需要一个普通桌面软件来打开、查看并在必要时修改这些文档。

InkMark 服务的就是这个过程：AI 或其他工具处理本地 Markdown 文件，InkMark 作为人查看和简单编辑文档的桌面界面。

## 产品定位

InkMark 是一个普通、所见即所得的 Markdown 桌面编辑器，与 Typora 属于同一产品类别。Typora 可以作为功能完整度和交互体验的内部参照。

编辑能力不是 InkMark 的特殊卖点。产品只需要把一个 Markdown 编辑器应有的查看、编辑和文件操作能力做完整、稳定、好用。

当前产品建设直接围绕功能完整性展开，不以用户调研或寻找目标用户作为下一阶段工作的前提。

## 核心能力

1. 直接打开本地 `.md` 文件，正确显示常见 Markdown 内容。
2. 完成日常需要的简单编辑、查找替换、图片处理和文件切换。
3. 始终保存为标准 Markdown 文件，不引入私有文档格式。
4. 与 AI 等外部工具处理同一批文件；外部修改发生后及时显示变化。
5. 人工存在未保存修改时，避免外部写入造成内容丢失，并提供清楚的冲突处理方式。

## 产品边界

- 不建设知识库、双向链接、数据库视图或插件生态。
- 文件树只用于普通的文件夹浏览、文件切换和基础文件操作，不扩展为知识库结构。
- 不追求复杂排版、专业出版或重型写作辅助能力。
- HTML、PDF 和富文本导出当前不需要。

## 发展方向

InkMark 按三个层次持续完善：

1. **可靠的本地 Markdown 编辑器**：常见文档能够正确打开、查看、修改和保存。
2. **完整的日常文档工具**：补齐查找替换、图片处理、Markdown 兼容性和普通文件树。
3. **面向 AI 的文件协同**：让外部修改及时可见，在人工与 AI 同时修改时保护内容，并逐步提供清晰的变化审阅能力。
