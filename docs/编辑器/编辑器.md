# 编辑器

## 职责与边界

提供所见即所得与源码编辑、Markdown 转换、选区和撤销、格式命令、查找替换、大纲及字数。文件读写由文档与保存模块处理；两种编辑器不各自持有独立的持久化正文。

## 当前实现

- `components/Editor.tsx` 组合 Milkdown、CommonMark、GFM 及项目插件；`components/SourceEditor.tsx` 使用 CodeMirror 6。
- `plugins/` 实现 YAML frontmatter、宽松换行、列表标记、任务列表、表格行列操作、单元格换行与复制等兼容行为。
- `editor-commands.ts` 及两个编辑器句柄供界面执行格式命令；`find-replace*` 与 `hooks/useFindReplace.ts` 处理查找、定位和替换。
- `hooks/useOutline.ts`、`hooks/useWordCount.ts` 从当前文档派生信息；源码侧结构提取集中在 `source-document.ts`。
- 大纲拖动移动章节：`outline-sections.ts` 计算章节正文区间与搬移结果（纯逻辑），`outline-move.ts` 接编辑器执行，`components/Outline.tsx` 负责拖动交互。拖到目标标题行上半区插到该章节之前、下半区插到该章节之后；整节连同全部子章节一起搬移，不改变标题级别。
- 大纲标题右键菜单提供「删除章节」「升级」「降级」：删除标题及其正文、全部子章节；升级或降级将本章和子标题整体调整一级，任一标题超出 H1–H6 时整次禁用。`outline-edit.ts` 负责结构计算，`outline-actions.ts` 核对当前文档并执行可撤销写回。
- 视图模式偏好全局保存于 store；纯文本/代码文件（文档类型见 `src/shared/openable-document.ts`）固定源码模式，由 `selectViewMode` 派生实际生效模式，切换到文本标签不改写偏好，切回 Markdown 标签自动恢复。文本标签下隐藏 Markdown 格式按钮组并禁用切换入口。

以上路径均相对于 `src/renderer/src/`。

## 状态与接口

标签 `sourceContent` 是正文真源。编辑器变更向 store 同步，装载正文时同步处理派生数据与未保存标志。Milkdown 的通知存在延迟，读取待同步编辑需使用编辑器句柄，不能把通知时点等同于用户最后一次输入。

`editor-state-cache.ts` 基于 `document-editor-state.ts` 按标签和模式缓存内部状态；正文匹配才恢复，否则废弃对应模式缓存。滚动与光标相关逻辑位于 `editor-scroll.ts`、`editor-position.ts`，标签关闭时须清理。

## 技术约束与专题

- 保持撤销历史按标签与模式隔离，不能让旧缓存覆盖外部重载或审阅正文。
- 大纲拖动搬移正文必须走可撤销的整篇替换（`replaceDocumentUndoable`），不能用 `setMarkdown`：后者重建编辑器状态会清空撤销历史。
- 所见即所得模式下标题节点位置与源码字符偏移不是同一坐标系，章节区间必须在序列化后的 Markdown 文本上计算；解析出的标题数量或层级与大纲不一致时放弃移动，避免搬错章节。
- 大纲移动的正文解析统一跳过 YAML 元信息并保留原文坐标；必须避开未闭合代码围栏，且只在顶层标题或文末边界切分和插入，防止拆开列表、引用等容器；写回前核对标题内容、顺序及容器归属，防止未闭合 HTML 块吞掉章节或相邻列表吸收标题；不能改变引用式链接定义的顺序，以免影响未移动链接；源码编辑器处于审阅只读状态时禁止移动。
- 大纲删除与升降级共用现有可撤销整篇替换，两种模式的替换均与前后输入隔离为独立撤销步骤；源码按编辑状态的行分隔符读取和写回，所见即所得有待同步输入时优先读取当前编辑内容，否则保留原始 Markdown。菜单执行前再次核对标签、模式、编辑器实例及正文，拒绝过时菜单；大纲与实时标题不匹配、存在未决审阅块或源码只读时禁用操作，待审阅块清空后允许继续调整结果。
- 删除章节只允许在顶层标题或文末边界切分，且不得移除引用式链接定义；升降级保留标题正文和容器归属。Setext 标题在一二级间保留下划线写法，顶层单行二级标题降级时转为 ATX；多行或容器内 Setext 标题转三级时禁用，避免改变正文语义。
- 当前支持 CommonMark 与已启用 GFM；数学公式与 Mermaid 未实现。保存要求语义正确，不要求字节一致。
- 不通过 HTML 扩展下划线、文字颜色等非标准格式。
- 查找默认不区分大小写并按原文匹配；可选择区分大小写、全字匹配、正则表达式和限定选区。源码模式搜索源码，所见即所得模式按连续可编辑文本段搜索，段落和图片等行内原子节点会切分文本段，正则锚点作用于各段；不能跨越这些边界匹配。限定选区时从选区起点扫描，匹配结果须完整落在选区内，正则断言和全字边界仍使用原文上下文。选区在正文被其他操作改变时失效，不能用旧范围替换。
