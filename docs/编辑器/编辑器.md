# 编辑器

## 职责与边界

提供所见即所得与源码编辑、Markdown 转换、选区和撤销、格式命令、查找替换、大纲及字数。文件读写由文档与保存模块处理；两种编辑器不各自持有独立的持久化正文。

## 当前实现

- `components/Editor.tsx` 组合 Milkdown、CommonMark、GFM 及项目插件；`components/SourceEditor.tsx` 使用 CodeMirror 6。
- `plugins/` 实现 YAML frontmatter、宽松换行、列表标记、任务列表、表格行列操作、单元格换行与复制等兼容行为。
- `editor-commands.ts` 及两个编辑器句柄供界面执行格式命令；`find-replace*` 与 `hooks/useFindReplace.ts` 处理查找、定位和替换。
- `hooks/useOutline.ts`、`hooks/useWordCount.ts` 从当前文档派生信息；源码侧结构提取集中在 `source-document.ts`。
- 视图模式偏好全局保存于 store；纯文本/代码文件（文档类型见 `src/shared/openable-document.ts`）固定源码模式，由 `selectViewMode` 派生实际生效模式，切换到文本标签不改写偏好，切回 Markdown 标签自动恢复。文本标签下隐藏 Markdown 格式按钮组并禁用切换入口。

以上路径均相对于 `src/renderer/src/`。

## 状态与接口

标签 `sourceContent` 是正文真源。编辑器变更向 store 同步，装载正文时同步处理派生数据与未保存标志。Milkdown 的通知存在延迟，读取待同步编辑需使用编辑器句柄，不能把通知时点等同于用户最后一次输入。

`editor-state-cache.ts` 基于 `document-editor-state.ts` 按标签和模式缓存内部状态；正文匹配才恢复，否则废弃对应模式缓存。滚动与光标相关逻辑位于 `editor-scroll.ts`、`editor-position.ts`，标签关闭时须清理。

## 技术约束与专题

- 保持撤销历史按标签与模式隔离，不能让旧缓存覆盖外部重载或审阅正文。
- 当前支持 CommonMark 与已启用 GFM；数学公式与 Mermaid 未实现。保存要求语义正确，不要求字节一致。
- 不通过 HTML 扩展下划线、文字颜色等非标准格式。
- 查找当前为不区分大小写的原文匹配，不支持正则或选区限定。
- 兼容场景与回归步骤见 [Markdown 兼容性](../markdown-compatibility.md)。
- 换行语义见 [换行说明](../line-break-mode.md)，排版与宽度见 [主题架构](../theme-architecture.md)、[正文宽度](../editor-width-design.md)。
- [Live Preview](../live-preview.md) 是需求与历史评估，不能作为当前实现说明。

修改内核、内容替换或序列化时按影响选择定向测试与兼容性场景，核心升级或大范围调整执行完整兼容性回归。整体关系见 [技术架构](../技术架构.md)。
