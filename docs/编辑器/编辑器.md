# 编辑器

## 职责与边界

提供所见即所得与源码编辑、Markdown 转换、选区和撤销、格式命令、查找替换、大纲及字数。文件读写由文档与保存模块处理；两种编辑器不各自持有独立的持久化正文。

## 当前实现

- `components/Editor.tsx` 组合 Milkdown、CommonMark、GFM 及项目插件；`components/SourceEditor.tsx` 使用 CodeMirror 6。
- `plugins/fast-serializer.ts` 替换 Milkdown 上游存在平方级数组拼接的默认序列化实现，保证大文档序列化维持线性复杂度；`plugins/doc-change-listener.ts` 替代 `@milkdown/plugin-listener`，避免在初始化和整篇替换时无条件触发全量序列化。
- `plugins/` 实现 YAML frontmatter、宽松换行、列表标记、任务列表、表格行列操作、单元格换行与复制等兼容行为。
- `editor-commands.ts` 及两个编辑器句柄供界面执行格式命令；`find-replace*` 与 `hooks/useFindReplace.ts` 处理查找、定位和替换。
- `hooks/useOutline.ts`、`hooks/useWordCount.ts` 从当前文档派生信息；源码侧结构提取集中在 `source-document.ts`。
- 大纲拖动移动章节：`outline-sections.ts` 计算章节正文区间与搬移结果（纯逻辑），`outline-move.ts` 接编辑器执行，`components/Outline.tsx` 负责拖动交互。拖到目标标题行上半区插到该章节之前、下半区插到该章节之后；整节连同全部子章节一起搬移，不改变标题级别。
- 大纲标题右键菜单提供「删除章节」「升级」「降级」：删除标题及其正文、全部子章节；升级或降级将本章和子标题整体调整一级，任一标题超出 H1–H6 时整次禁用。`outline-edit.ts` 负责结构计算，`outline-actions.ts` 核对当前文档并执行可撤销写回。
- 视图模式偏好全局保存于 store；纯文本/代码文件（文档类型见 `src/shared/openable-document.ts`）固定源码模式，由 `selectViewMode` / `resolveTabViewMode` 派生实际生效模式，不改写全局偏好。超过 1 MB 的 Markdown 文档在所见即所得模式下使用 `components/LargeMarkdownReader.tsx` 与 `large-markdown-chunks.ts` 提供的分块惰性只读阅读视图（按块边界切分并仅渲染可视区周边片段，支持主题、大纲跳转、字数、复制、图片预览、外链跟随与顶部源码切换提示，禁用大纲拖动与章节编辑；编辑在源码模式下完成，源码与只读阅读之间可直接双向切换）。源码模式下不预先装载隐藏的所见即所得编辑器，文本标签下隐藏 Markdown 格式按钮组并禁用切换入口。

以上路径均相对于 `src/renderer/src/`。

## 状态与接口

标签 `sourceContent` 是正文真源。编辑器变更向 store 同步，装载正文时同步处理派生数据与未保存标志。Milkdown 的通知存在延迟，读取待同步编辑需使用编辑器句柄，不能把通知时点等同于用户最后一次输入。

`editor-state-cache.ts` 基于 `document-editor-state.ts` 按标签和模式缓存内部状态；正文匹配才恢复，否则废弃对应模式缓存。滚动与光标相关逻辑位于 `editor-scroll.ts`、`editor-position.ts`，标签关闭时须清理。

## 技术约束与专题

- 保持撤销历史按标签与模式隔离，不能让旧缓存覆盖外部重载后的正文。
- 大纲拖动搬移正文必须走可撤销的整篇替换（`replaceDocumentUndoable`），不能用 `setMarkdown`：后者重建编辑器状态会清空撤销历史。
- 所见即所得模式下标题节点位置与源码字符偏移不是同一坐标系，章节区间必须在序列化后的 Markdown 文本上计算；解析出的标题数量或层级与大纲不一致时放弃移动，避免搬错章节。
- 大纲移动的正文解析统一跳过 YAML 元信息并保留原文坐标；必须避开未闭合代码围栏，且只在顶层标题或文末边界切分和插入，防止拆开列表、引用等容器；写回前核对标题内容、顺序及容器归属，防止未闭合 HTML 块吞掉章节或相邻列表吸收标题；不能改变引用式链接定义的顺序，以免影响未移动链接；源码编辑器只读时禁止移动。
- 大纲删除与升降级共用现有可撤销整篇替换，两种模式的替换均与前后输入隔离为独立撤销步骤；源码按编辑状态的行分隔符读取和写回，所见即所得有待同步输入时优先读取当前编辑内容，否则保留原始 Markdown。菜单执行前再次核对标签、模式、编辑器实例及正文，拒绝过时菜单；大纲与实时标题不匹配或源码只读时禁用操作。
- 删除章节只允许在顶层标题或文末边界切分，且不得移除引用式链接定义；升降级保留标题正文和容器归属。Setext 标题在一二级间保留下划线写法，顶层单行二级标题降级时转为 ATX；多行或容器内 Setext 标题转三级时禁用，避免改变正文语义。
- 当前支持 CommonMark 与已启用 GFM；数学公式与 Mermaid 未实现。保存要求语义正确，不要求字节一致。
- 不通过 HTML 扩展下划线、文字颜色等非标准格式。
- 查找默认不区分大小写并按原文匹配；可选择区分大小写、全字匹配、正则表达式和限定选区。源码模式搜索源码，所见即所得模式按连续可编辑文本段搜索，段落和图片等行内原子节点会切分文本段，正则锚点作用于各段；不能跨越这些边界匹配。限定选区时，正则只扫描选区内的文本，选区首尾作为匹配边界，正则断言及替换引用也只使用选区内的上下文。按原文查找时，仍以完整文本判断全字边界。选区在正文被其他操作改变时失效，不能用旧范围替换。全字匹配在正则扫描时检查边界，避免在长单词内部反复扫描同一后缀。
- 兼容场景与回归步骤见 [Markdown 兼容性](../markdown-compatibility.md)。
- 所见即所得列表在首段行首退格退出一级，顶层项成为顶格正文（保留两步退格）；当光标位于列表后的空段落再按退格时，删除该空段落并将光标移回上一段列表末尾；编辑导致同类型且同标记符号（无序 `bullet` 一致、有序 `bulletOrdered` 一致）的列表直接相邻时，自动合并为同一连续列表（有序列表续接编号），不同类型或不同标记符号的列表保持分开，支持正常撤销。Delete 删除右侧完整字符。源码模式每次退格删除光标前一个字符，包括列表标记后的空格及行首缩进。删除整行按实际换行划定范围，并保留未选中的子项。表格 Enter 纵移，Tab 横移。原问题复现及验收示例见[编辑交互问题与优化建议](./编辑交互问题与优化建议.md)。
- 源码标题和跨段行内格式根据整个选区统一设置或取消，标题转换保留段间空行。所见即所得整行删除包含选区完整覆盖的独立分隔线。
- 源码模式下，选中强调文字的正文并设置行内代码时，原有强调标记保留在反引号外。所见即所得模式下，跨分隔线取消同类列表时按列表分别处理，保留分隔线、未选中的相邻项和原选区。
- 源码模式切换标题、列表或任务格式时，位于正文开头的光标或选区端点随正文移动。创建空列表项后，光标位于标记之后，可直接输入。
- 换行语义见 [换行说明](../line-break-mode.md)，排版与宽度见 [主题架构](../theme-architecture.md)、[正文宽度](../editor-width-design.md)。
- [Live Preview](../live-preview.md) 是需求与历史评估，不能作为当前实现说明。

修改内核、内容替换或序列化时按影响选择定向测试与兼容性场景，核心升级或大范围调整执行完整兼容性回归。整体关系见 [技术架构](../技术架构.md)。
