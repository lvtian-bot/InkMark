# 文档与保存

## 职责与边界

管理标签、文件打开、普通保存、另存、关闭及外部文件变化的用户决策。正文编辑由 [编辑器](../编辑器/编辑器.md) 负责。

## 当前实现与状态

- `src/renderer/src/stores/useStore.ts` 保存标签正文、路径、未保存标志、修改时间和位置；`hooks/useFile.ts` 组织文件操作与关闭流程。
- 打开通过 `window.inkmark` 请求主进程读取；`src/main/stable-file-read.ts` 核验读取期间的文件状态并按严格 UTF-8 解码。主进程对超限（10 MB）、非 UTF-8 与符号链接文件返回明确的拒绝原因；用户主动触发的打开、重载与冲突比对都会展示具体原因并终止，仅文件不存在时按丢失提示。相同文件复用已有标签。
- 普通保存入口在 `src/main/index.ts`：比较已知修改时间，冲突返回渲染层处理；经差异对比后明确选择覆盖磁盘版本，才按最新已知修改时间写入。同目录临时文件替换原文件，更新修改时间及磁盘基线。
- 普通保存由主进程检查原文件的覆盖权限。通过系统对话框、文件关联、启动参数或原生最近文件菜单打开的文件可直接保存。明确打开的工作区及可信的最近工作区允许保存目录内的文件。拖放或文档链接打开的范围外文件，首次手动保存时通过系统确认框显示目标完整路径，确认只授权当前会话的该文件。
- 另存可由保存对话框选择目标；跨目录时按正文实际引用复制本地图片并改写副本地址，图片收集失败时不写正文。返回实际落盘正文并同步标签、可见编辑器和磁盘基线，避免后续保存写回旧图片路径。复制规则见 [图片与链接](../图片与链接/图片与链接.md#另存图片)。
- `auto-save.ts` 判定资格，`useFile` 按标签维护定时器；默认关闭，开启后延迟 3 秒。自动保存只写入已有路径、已获覆盖权限且不存在待处理外部更新或冲突的文档，等待授权或处于外部冲突期间保留未保存状态。
- 普通正文未保存时按标签保存本机恢复草稿，约每秒更新；启动后可选择恢复或暂不恢复。保存或丢弃时清理对应草稿，正常退出前等待清理。
- 恢复有路径的草稿时比较文件修改时间和原始正文；原文件变化、不可读取或已打开时恢复为新文档，避免覆盖原文件。新建文档同样恢复为未保存文档。草稿写入采用临时文件替换；中断前尚未写入的最后一段内容无法保证恢复。
- 恢复为新文档时保留来源路径供文档类型判断、相对链接与图片解析，以及另存时复制图片；来源路径不作为直接保存目标。清理草稿失败时保留重试机会，取消关闭后继续保护未保存内容。
- 安装更新前按关闭流程清理草稿；安装启动失败或发生异常而窗口继续打开时，重新安排未保存正文的草稿保存。

## 外部更新与关闭

`src/main/file-watch-manager.ts` 监听文件所在目录并跟踪单文件状态，合并事件、识别文件消失及自身写入。`useFile` 接收事件并检查文件状态，`file-conflict-decision.ts` 定义用户决策。

干净文档出现外部更新提示时，不自动替换正文，并锁定该标签编辑（保留阅读、滚动与复制），避免未重载前误编辑吃掉提示；用户手动点击「重新加载」后读取磁盘最新版并解锁。有未保存修改时（包括保存或自动保存瞬间遇到修改时间冲突），立即暂停该标签自动保存、锁定继续编辑，并弹出统一差异对比对话框，默认推荐「另存为新文件…」，同时提供「使用磁盘版本」「覆盖磁盘版本」「取消」四项选择；取消后保持只读与自动保存暂停，顶部常驻冲突提示条供随时另存或再次查看差异处理。关闭标签和窗口必须处理未保存内容，保存失败或取消必须保留标签。

## 必须保持的约束

- 所有保存读取标签 `sourceContent`，不新增独立正文状态。
- 成功读取只登记文件已打开，不能授予覆盖权限。保存授权及落盘使用解析后的目标路径，工作区内的目录联接不扩大授权范围。
- 文件读取、保存及确认等待期间，重新核对标签和文档身份，避免异步结果落到其他文档。
- 关闭、复用标签时清理编辑器缓存与监听状态。
- 普通保存主要依靠修改时间检查，不是文件锁，不能描述为绝对并发保护。
- 恢复草稿不得作为原文件直接写入；草稿路径和磁盘基线未经核验时只能恢复为新文档。
