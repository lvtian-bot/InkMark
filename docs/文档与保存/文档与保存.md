# 文档与保存

## 职责与边界

管理标签、文件打开、普通保存、另存、关闭及外部文件变化的用户决策。正文编辑由 [编辑器](../编辑器/编辑器.md) 负责，逐项审阅的改动模型和专用写回由 [外部审阅](../外部审阅/外部审阅.md) 负责。

## 当前实现与状态

- `src/renderer/src/stores/useStore.ts` 保存标签正文、路径、未保存标志、修改时间、位置和审阅标志；`hooks/useFile.ts` 组织文件操作与关闭流程。
- 打开通过 `window.inkmark` 请求主进程读取；`src/main/stable-file-read.ts` 核验读取期间的文件状态并按严格 UTF-8 解码。主进程对超限（10 MB）、非 UTF-8 与符号链接文件返回明确的拒绝原因；用户主动触发的打开、重载与冲突比对都会展示具体原因并终止，仅文件不存在时按丢失提示。相同文件复用已有标签。
- 普通保存入口在 `src/main/index.ts`：比较已知修改时间，冲突返回渲染层处理；明确选择保留并覆盖后才可强制保存。同目录临时文件替换原文件，更新修改时间及磁盘基线。
- 普通另存可由保存对话框选择目标；复制关联图片后写入目标。它与审阅副本的排他新建规则不同。
- `auto-save.ts` 判定资格，`useFile` 按标签维护定时器；默认关闭，开启后延迟 3 秒，仅用于有路径的未保存文档，整个审阅会话暂停。

## 外部更新与关闭

`src/main/file-watch-manager.ts` 监听文件所在目录并跟踪单文件状态，合并事件、识别文件消失及自身写入。`useFile` 接收事件并检查文件状态，`file-conflict-decision.ts` 定义用户决策。

干净文档出现外部更新提示，不自动替换正文；有未保存修改时提供冲突选择。用户选择审阅后固定本轮版本。关闭标签和窗口必须处理未保存内容与未决审阅，保存失败或取消必须保留标签。

## 必须保持的约束

- 所有保存读取标签 `sourceContent`，不新增独立正文状态。
- 文件读取、保存及确认等待期间，重新核对标签和文档身份，避免异步结果落到其他文档。
- 关闭、复用标签时清理编辑器缓存、监听与审阅状态。
- 普通保存主要依靠修改时间检查；审阅保存额外比较原始正文。两者都不是文件锁，不能描述为绝对并发保护。
- 未保存正文只在内存中，不提供异常中断恢复。
