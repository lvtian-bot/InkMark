# 外部改动审阅（技术设计）

本文档记录外部改动审阅（Review Mode）的技术架构、核心模块、数据流转及并发/写回保护机制，供后续维护与演进参考。需求与交互说明参见 [change-review.md](./change-review.md)，讨论背景参见 [change-review-concurrency-proposal.md](./change-review-concurrency-proposal.md)。

## 架构概览

审阅系统分布在 Electron 主进程、Preload IPC 层以及渲染进程中：

```
+-------------------------------------------------------------+
|                        渲染进程 (Renderer)                   |
|                                                             |
|  [useFile / useStore] <---> [review-store]                  |
|          |                         |                        |
|          v                         v                        |
|  [ReviewToolbar]           [review-diff] (jsdiff 按行对比)   |
|          |                         |                        |
|          v                         v                        |
|  [SourceEditor] <--------> [review-extension] (CodeMirror 6)|
|                               (装饰层 / Widget / 折叠)      |
+-------------------------------------------------------------+
                             ^
                             | IPC (file:saveReviewed / dialog:saveReviewCopy)
                             v
+-------------------------------------------------------------+
|                        主进程 (Main)                        |
|                                                             |
|  [review-file-save.ts]                                      |
|    - saveReviewedFileVersion: 写入前稳定重读与 mtime/正文比对 |
|    - writeNewReviewCopy: 排他创建 ('wx' 标志) 保证不覆盖已有   |
+-------------------------------------------------------------+
```

## 核心设计与数据模型

### 1. 投影模型 (Projection Model)

编辑器正文始终保持为「已接受投影」：

- **已决定的改动**直接物化（写入）编辑器文档正文（`sourceContent` 是单一真源）。
- **未决的改动块**仅存在于 CodeMirror 装饰层中：
  - **删除文本**：在实际正文上添加删除线、红色背景样式（`Decoration.mark`）。
  - **新增文本**：不插入实际文档，而是通过 `Decoration.widget` 挂载在行首/插入点，呈现绿色背景。
  - **操作按钮**：纯删除块按钮挂载在删除末尾；替换/新增块按钮挂载在对应位置，确保折叠时不会意外隐藏。

### 2. 磁盘快照与行级 Diff

- 每个标签页维护一份最近确认过的磁盘内容快照 `DiskSnapshot { content, mtime }`。
- 进入审阅时，计算增量：`diff(磁盘快照, 最新磁盘内容)`。
- 对比粒度采用**整行对比**（jsdiff `diffArrays`），将连续改动的行合并为单个改动块（替换、纯增、纯删），避免按词对比导致的碎片化问题。

### 3. 编辑状态隔离与模式约束

- 审阅模式仅在**源码模式**（CodeMirror 6）下运行。
- 检测到待审块时，如果处于所见即所得模式，会自动切入源码模式并锁定模式切换。
- **锁定编辑**：存在未决块时编辑器设为只读，避免用户并发编辑导致锚点偏移混乱。未决块处理完毕后恢复可编辑。

## 会话流转与关键路径

### 1. 进入审阅

1.  **补齐真实编辑**：从 Milkdown 或 CodeMirror 中提取尚未同步的最新编辑内容，更新为当前正文。
2.  **文本换行规整**：仅规整换行符（CRLF/LF），绝不重新序列化正文排版，防止因格式变动误杀差异。
3.  **固定本轮版本**：读取磁盘文件并固定为本轮外部版本，存入 `diskSnapshots`。
4.  **生成并锚定待审块**：将 diff 块锚定到当前正文坐标。若无法注入（如后台标签），推入 `queuedChunks` 等待切换时排空（drain）。
5.  **开启审阅工具栏**：展示常驻提醒「审阅期间请勿使用其他软件或 AI 修改此文档，以免内容冲突或丢失」。

### 2. 逐项或批量决策

- **逐项决策**：点击单个块的接受/拒绝，更新编辑器正文与装饰层，`pendingReviewCount` 减 1。
- **批量决策**：
  - 全部接受：将全部新增文本应用入正文，移除所有删除块。
  - 全部拒绝：直接丢弃新增 widget，保留原删除内容。
- **弹窗二次确认**：
  - 批量决策（全部接受/全部拒绝/退出审阅）在执行前均需弹窗确认。
  - 最后一项处理完后，弹出保存确认弹窗；取消确认时保留会话与内存正文，工具栏显示「保存审阅结果」按钮供随时重试。

### 3. 保存与冲突处理

所有写回操作必须经过主进程专用入口 `saveReviewedFileVersion`：

```
[用户触发保存]
       |
       v
[读取当前磁盘内容与 mtime]
       |
  一致 / 冲突？
  /         \
(一致)      (冲突 / 外部已修改 / 读取失败)
  |                  |
[调用主进程           [弹出冲突提示]
 file:saveReviewed]   用户选择「另存新版本」或「取消」
  |                  /                     \
(主进程再次核验)   (另存新版本)              (取消)
  /          \          |                     |
(通过)     (冲突)   [调用主进程            [保留当前标签内存结果]
  |          |       dialog:saveReviewCopy]   工具条常驻，可重试
[原子替换原文件] |     (排他创建 'wx')          自动保存暂停
  |          +---> 仅允许另存新版本
[结束审阅会话]
```

1.  **写前核验**：主进程写入前通过 `readStableTextFile` 读取磁盘文件，严格核对文件内容与 `mtime` 是否与进入审阅时的快照一致。
2.  **发生外部修改**：若磁盘版本与快照不符，主进程拒绝写入原文件，渲染进程弹出提示，**仅提供另存新版本**与**取消**，绝不提供强制覆盖选项。
3.  **另存排他保护**：调用 `dialog:saveReviewCopy` 时，主进程以 `'wx'` 排他标志新建文件，禁止覆盖已有文件或原文件。另存成功后，当前标签切换到新路径，原文件完整保留外部修改。

## 模块组织索引

| 模块路径                                        | 职责说明                                                               |
| ----------------------------------------------- | ---------------------------------------------------------------------- |
| `src/renderer/src/review/review-diff.ts`        | 文本规整、基于 jsdiff 的按行差异计算与锚点验证                         |
| `src/renderer/src/review/review-store.ts`       | 审阅状态运行时编排（快照管理、待审队列、入库与结束）                   |
| `src/renderer/src/review/review-extension.ts`   | CodeMirror 6 扩展：装饰层渲染（删除线/新增widget）、折叠逻辑与事件绑定 |
| `src/renderer/src/review/review-resolution.ts`  | 全部接受/拒绝逻辑处理                                                  |
| `src/renderer/src/components/ReviewToolbar.tsx` | 编辑区顶部常驻审阅工具条与并发提醒 Banner                              |
| `src/renderer/src/hooks/useFile.ts`             | 外部变更监听、冲突流转调度、保存确认与审阅会话生命周期                 |
| `src/main/review-file-save.ts`                  | 主进程写回核验（版本比对）与排他创建副本逻辑                           |
